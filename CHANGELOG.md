# Changelog

## 1.0.0 - 2026-09-03

- Initial open-source release.
- SHP to structured TXT coordinate export.
- TXT to SHP geometry restoration.
- Point, LineString and Polygon support, including polygon outer/inner rings.
- CRS transformation with common CGCS2000 zones and custom EPSG codes.
- Traditional GIS X/Y axis order handling for GDAL 3+/PROJ.
- QGIS background-thread execution and progress reporting.
- Native-style QGIS interface with separate Parameters and Log tabs.
- Official QGIS Plugin Repository metadata, GPL-2.0-or-later license, documentation and unified icon.
